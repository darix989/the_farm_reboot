# muddy-water tiles

Source: gamedeveloperstudio.com — "Repeating water tiles" pack, `muddy-water` colourway.
These five 256x256 PNGs (`flat-top-one`, `flat-top-two`, `crest-top-one`, `trough-top-one`,
`water-color`) tile left-to-right in any order and are baked into one pond prop,
`public/assets/farm-kit/water/pond-muddy.png`, by `scripts/build-pond-asset.mjs`
(`npm run assets:pond`).
